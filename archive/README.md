# Development archive

Looking for a panel to print? Go to **[Finished models](../models/README.md)**.

This directory retains earlier drafts, experiments, source inputs, slice evidence, and generation/validation scripts. Files were moved here byte-for-byte; the catalog maps and checks them. No historical model was discarded.

- `outputs/`: historical outputs and exact source copies of current models.
- `work/`: generation and validation scripts plus their intermediates.
- `sources/`: user-supplied lightbox project.

The three directories remain siblings so existing scripts retain their relative paths. Run scripts from a working copy; several overwrite outputs. See [reproduction instructions](../docs/reproduction.md). Historical reports may contain old absolute paths; resolve their filenames under this archive.

Do not infer successful printing from names such as “ready” or from exported G-code. Current evidence is summarized in the human-facing model folders and docs.
